# Definir: o problema dos eixos

A Usinagem Serra Alta fabrica eixos para bombas de água. Nos últimos meses, o cliente principal reclamou de atrasos, e a fábrica vem jogando fora cerca de 10 % dos eixos porque o diâmetro sai da especificação. Você foi chamado como green belt para conduzir um projeto DMAIC.

O ato 8 é o caso final da campanha. Cada missão é uma fase: definir, medir, analisar, melhorar e controlar. Os dados das fases seguintes são gerados para você, com efeitos escondidos que você vai precisar encontrar.

## O que fazer

Responda às perguntas do termo de abertura: o CTQ, a meta e o escopo do projeto. Esta missão é só de perguntas.
